Connect Your GitHub Account

We use a Personal Access Token to create your portfolio repository. Your token is only used during this session and is never stored.

How to create a GitHub token (click to expand)
  1. Go to github.com/settings/tokens/new
  2. Give it a name like Data Academy Portfolio
  3. Set expiration to 7 days
  4. Under Select scopes, tick repo
  5. Click Generate token and copy it immediately

Starts with ghp_ or github_pat_

Your Repository

Deploy to Vercel (free)

  1. Go to vercel.com/new and sign in with GitHub
  2. Click Import next to your new repository
  3. Leave all settings as defaults — click Deploy
  4. Your portfolio is live at a .vercel.app URL within 60 seconds

Adding Your Profile Photo

On GitHub, open your repo → public/ folder → upload your photo file → name it ando-headshot.jpeg (or update the path in lib/portfolio-config.json). Vercel auto-deploys on every commit.

Editing Your Portfolio Later

Open lib/portfolio-config.json in your GitHub repo and edit the values directly. Vercel auto-deploys every change within 60 seconds.

For bigger edits, paste the relevant section into Claude and describe what you want.
